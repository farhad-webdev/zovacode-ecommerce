# ZOVACODE® Streetwear

A responsive, single-page streetwear storefront built with HTML, CSS, and vanilla JavaScript.

All storefront photography is stored locally in the `assets/` folder.

## Run locally

Open `index.html` in a browser or serve this folder with any static file server. No build step or package install is required.

## Deploy

The site is published from the `main` branch root with GitHub Pages. Push updates to `main` to publish them.

## Storefront interactions

- Browse products by category and choose a size.
- Search the sample catalog and add items to a bag.
- Adjust bag quantities; the bag is saved in browser storage.
- Preview checkout, account, and newsletter flows.

Checkout, accounts, and newsletter signup are front-end demos and are not connected to payment, authentication, or mailing-list services.
